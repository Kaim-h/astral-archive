# Astral Archive

Astral Archive is a practical, illustrated Linux desktop shell and a planned spatial file Archive, built around Quickshell, Qt Quick/QML and JavaScript. It integrates with Hyprland and existing Linux services rather than replacing the compositor.

The design combines a quiet storybook-library / observatory metaphor with ordinary desktop priorities: useful controls, clear navigation, responsive interactions, keyboard access, recoverability and safe filesystem behavior.

## Implementation status

The tracked shell includes the illustrated launcher, Archive Capsule, utility controls, Veranda wallpaper selector and Celestial Gallery. The separate Archive study includes B6 native geometry/interaction foundations and B7 symbolic representations and mixed furnished cubbies. It includes universal Scroll Case transport and explicit synthetic checkpoint Save/Load; it is not imported by the production shell. Its records and file operations are synthetic; it is not a production file manager.

See the [Archive architecture review and development lessons](docs/architecture/ARCHIVE_INTERDEVELOPMENT_REVIEW_2026-11-24.md) for the pinned technical source map and advisory recommendations.

Read the [current state](docs/development/CURRENT_STATE.md), [roadmap](docs/archive-roadmap.md) and [native Linux bring-up guide](docs/bringup.md). Baseline preparation is still under review. This is not a release or evidence of successful target desktop validation.

## Verification and assets

Static checks, JavaScript unit tests, browser studies, offscreen Qt Quick, actual Quickshell and target desktop validation are distinct evidence classes. Historical results are recorded in the technical documentation; the migrated baseline has not yet been runtime-tested.

Personal wallpapers, fonts, artwork and runtime state are not bundled. Wallpaper metadata serves as a theme reference, not permission to redistribute the associated images. Obtain local assets separately from authorized sources. See [asset guidance](docs/assets.md) and [design language](docs/product/VISION_AND_DESIGN_LANGUAGE.md).
