# Astral Archive — contributor entry point

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the technical, design, testing, documentation and Git rules applicable to all contributors, including automated tools. Start with [README.md](README.md) and the [documentation index](docs/README.md).

Before editing, inspect current branch and head, open pull requests and the applicable source, tests and accepted technical requirements. Read current-state and active-work documents when available. Reuse the existing topic branch and PR. Do not commit to main, merge, force-push, delete branches or change visibility without the applicable owner authorization; direct main commits and force-pushes are not part of normal contribution workflow. Report exact checks, failures and limitations. Never infer runtime validation from static checks or prototypes.

This repository is currently an incomplete baseline preparation checkpoint. Do not begin ordinary development until a complete baseline is integrated and development is authorized. The repository must remain independently usable; no private conversation history is required.
