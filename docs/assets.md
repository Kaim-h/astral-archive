# Fonts and wallpapers

These assets are **not** required for Batch 6's functional code.

- The current `.gitignore` excludes `assets/fonts/` and `assets/wallpapers/`.
  New files there will not appear in a normal Git commit. The `.gitkeep`
  placeholders already tracked may remain as directory markers.
- Choose one primary inscription font and a reliable fallback. For an
  appropriately licensed bundled font, we can later use QML `FontLoader`
  and a relative `assets/fonts/...` URL. For a personal-use-only font, install
  it locally on Linux and reference the installed family name instead.
- Prepare Evening, Twilight and Midnight wallpaper choices, but judge final
  cropping/scale behind the real panels when the Linux setup exists.
- Copyright matters: only redistribute assets when permissions explicitly
  allow it. If redistribution isn't permitted, keep user-specific local paths
  and provide a configuration example rather than embedding the binaries.
- No font or wallpaper is included in the Batch 6 archive.
