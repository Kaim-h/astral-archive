**Status:** design closeout, November 25, 2026; independent review and owner integration pending. No native implementation or new runtime evidence. The owner has approved proceeding from S19r4 to closeout. This contract consolidates the [workshop](../research/prototypes/2026-11-24/b8/README.md), superseding conflicting earlier B8 directions while preserving B6/B7 physics, ownership, and safety contracts. See [feature references](../research/prototypes/2026-11-24/b8/S20_REFERENCE_MATRIX.md) and [Developer handoff](../development/B8_IMPLEMENTATION_HANDOFF.md).

## 1. Architecture and identity

| Layer | Accepted role | Data responsibility |
|---|---|---|
| Map Room | Expandable, strictly top-down architectural atlas, pan/zoom/fit; renameable starter Main Hall | Room identities, footprints, shared doorways, map display preferences |
| Room | Strict plan or centered shallow perspective | Interior, Shelf footprints, orientation, shared openings, surface appearance |
| Shelf | First frontal inspection level; architectural casework with mixed supported storage | Stable container, interior width/height and independent plan depth, fixtures and representations |
| Cubby | One recursively nestable configurable container type | Parent footprint, independent interior dimensions, view scale, fixtures and nested cubbies |
| Fixtures / representations | Boards, racks, upright holders/cradles, compatible mounts and symbolic artwork | Placement, support, identity, ownership; file records distinct from app identities |

No mandatory intervening Cubby for directly supported Shelf objects. Rack cells are physical partitions, not folders. Keep filesystem identity, virtual organization, physical ownership, placement, appearance and transient view state separate. No visual edit silently changes real files. No file representations in the two upper plan layers. B8 Room furniture is Shelf-only. Rectangular Rooms are the initial scope, not a permanent restriction on the boundary model.

## 2. Dimensions, physical support and ownership

- Stored geometry is authoritative; camera fitting never mutates geometry, contents or outer inspection frame. Parent footprint and container interior are distinct. Reconcile actual common Shelf width across Room footprint, framing/overhang and frontal interior; depth and frontal height remain independent. Define units, anchors, occupied bounds and any model migration before native integration. No fixed illustrative plate ratio in production.
- Growth preserves positions, object sizes and identities. Block invalid shrink with explanation; optional separately previewed rearrangement may be offered. No implicit unrelated scaling, reflow, compaction, evacuation or displacement. Support movement carries dependents without scaling them. Define eligibility for flat module tops, contact, and overhead clearance. Rectangular usable interior, additive ornament with clearance accounted for. Experimental ~30% support overhang is not a production constant.
- Recover the original flat Lighting Lab board, as in S18r3, in canonical theme roles without extra depth/gradients. Independent adjustable general-purpose support, not a fixture that generates books. Derive contact from asset anchors and board top. Books are independent application representations, supported and not manually resizable. Scrolls are not manually resizable. Preserve family-specific compatible fixtures and selected-object sizing; no blanket replacement art.
- Same rack behavior in Shelf or Cubby. Reuse B6r12b3/B7-N2 pre-settling, bounded solver, insertion, reflow, capacity, cancellation, ownership and approvals. External dimensions, cell radius and individual scroll radius independent. Established native width 180–1800, height 160–1500, cell radius 38–76, default 64/new at least 60 and approval below 60; browser scroll tiers [7,9,12,15,18]. Compact B8 study radii 12–48 and sample sizes are not replacement native values. Distinct diamond handle/radius guide versus square exterior handles. Do not snap physical scroll motion.
- Universal Scroll Case preserves file ID, metadata, preferred family/variant, explicit compact preference, radius, provenance and order; compatible reinsertion restores preferred representation. Local direct move, Case across containers. Cradle presentation is not ownership. Explicitly confirm removal affecting contents, preview affected count, recursively evacuate files atomically, mark stale origins, preserve existing Case entries, exact Undo. App unplacement is separate; never convert app identity to a file or launch/delete real apps in synthetic tests.

## 3. Interaction, appearance transactions and geometry

Browse activates/enters; Arrange selects/manipulates, including double click. Explicit navigation may resolve Arrange then enter. No production click-cycling of preview states. Metadata and general controls available in both modes; hide tooltip during active manipulation, restore afterward. Preserve B7u3 holder selection, presentation, threshold drag/swap, return and Escape, one identity and reserved support.

Appearance: live edits; dismissal, context switch, close and Browse commit valid changes; Escape reverts current session. One Undo per changed menu session, not slider sample. Valid structural arrangements commit on Browse, including pending numeric edits and creation. Flush/validate numeric edit before selection change; invalid values retain old target and typed value with feedback. Explicit cancellation and exact Undo remain. **Implicit commit does not override B6/B7 confirmation, physical settling, reflow/overflow, transfer, removal or invalid-resolution requirements.** No silently discarded dependents. Unified chronological Undo across appearance/geometry remains an implementation proposal (testers retain separate histories).

Transient right-click context, keyboard equivalents, no permanent inspector. Shelf root five actions: direct Appearance, Shelf dimensions, Add furniture, Grid and snapping, Undo. Structural controls first in Arrange. Map root Appearance, Add Room, Grid and snapping, Fit map, Undo. Target-specific scope; local Cubby glazing separate from global Shelf. Group/filter long lists where useful; one-level hover-open action flyout right or left if space, keyboard/click fallback, no nested cascades. Property dropdowns require deliberate choice; preserve four-visible scrollable emblem gallery. Independent backing fields nonoverlapping, ordinary controls not gated by Secrets. Direct manipulation primary, exact numeric entry secondary. Grid independent from snap, same local interval/origin; relative gesture increments, exact numeric unsnapped; collision/contact priority. Freeze camera during gestures.

## 4. Map and shared doors

Restrained engraved surveyor chart, strict top-down. Title and optional subtitle at distance; simplified actual floorplan/H Shelf footprints on zoom, not full Room renderer or floating file thumbnails. World-anchored synthetic coherent terrain contour option from S19r4 (CC0 method, not surveyed geography), None/Subtle/Engraved and density in theme engraving role. Chart title/subtitle, compass/family mark; map-level frame, label and mark defaults and local overrides. Map-only framing is decorative, not wall geometry.

Move/resize/rename Rooms, focus selected Room or door, restore preceding camera on dismissal/Overview; direct refocus, stable camera during gestures. Larger handles, nearby magnetic wall alignment and suggested clear door locations, free placement available. Optional connections; no corridors. One shared doorway identity defines aligned openings in both adjacent Rooms, in map, plan and perspective. Multiple on same wall. Drag center or resize endpoints; preview/commit merge of same-pair contacting openings, Undo restores original doors; no merge across different pairs. Delete/Backspace in Arrange outside editable controls removes only selected door, no confirmation. Clamp within contiguous clear shared segment without jumping across obstruction/corner; preserve existing openings on Room move/resize where possible, preview separation and Keep/Restore if not. Do not move existing Shelves to fit doors. No arbitrary maximum width independent of wall. Exact tolerance, clearance, wall thickness, standalone entrance policy and solver remain open; 12/60/70 study units are not standards.

## 5. Room and navigation

Accepted H stepped-cornice plan glyph, centered shallow perspective with actual selected Shelf profile/theme, no independent Room-side Shelf appearance. Nine stone floors and eight walls from S14, minimal grout, no timber. Zero yaw/roll, initial tilt 22 degrees (20–30 range); camera distance 2.6× larger dimension and cutaway details provisional. Common projection for floor/walls/furniture/openings, inverse floor mapping, frozen gesture camera. Native renderer open; event-driven caching, avoid idle/hidden work. CPU rasterizer is research, not mandatory architecture.

Room→Shelf: S16r3 method A accepted, initial 500 ms; 2D tilt-and-focus, perspective focus-and-enter, reverse return; reduced motion instant, Skip/Escape, mode guards. Actual current Shelf geometry and appearance define source/destination; uniformly fit, no artificial stretching or fixed plate ratio, same shared front, freeze anchors and rotation on entry, restore camera on return. 900 ms imperfection accepted; don't reopen just to perfect slow animation. Map→Room focus/enlarge and optional tilt to Room preference is proposed; exact duration not separately accepted. Shelf→Cubby recursive entry follows short restrained consistent motion; exact timing to verify. Fixed frame and Back/breadcrumb identity preserved.

## 6. Visual identity and inheritance

Canonical desktop Theme.qml role palettes (Evening/Twilight/Midnight) by default. Explicit local palette override does not propagate to children; family inherits immediate parent unless overridden; explicit None distinct from Architectural. Independent profile, surface/backing and local glazing where applicable. Related but distinct architecture; increasingly rich ornament at closer scale, no mandatory density percentages. Flat inspection art, no extra perceived depth across catalogue; remove stone/recess gradients, retain functional glazing treatment. Early 3D books abandoned for scalability, especially Observatory. Correct Room to match canonical Shelf colours, not inverse. Satin glazing, reverse frost, plausible hinges/pull, recessed backing not a door, additive ornament and independent engraving fields. S11r1 76 primary/9 secondary catalogue is reference, not blanket acceptance of every artwork. Secondary Bestiary fang unresolved.

Application books use current Book.qml/ApplicationService/AppMatching policies for spine, title/ornament, cover identity, running/focused status and count. Eventual three coordinated theme variants per app identity required; swatches/mapping not settled, no random reassignment. Static HTML bookmarks are a bounded demonstration, not accepted final motion. Separate book redesign later. No 3D asset pipeline.
