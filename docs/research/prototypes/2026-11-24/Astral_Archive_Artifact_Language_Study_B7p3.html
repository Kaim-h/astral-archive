Artifact language study / B7p3

Focused redraw: leather pouch, wrapped parcel, armillary sphere, astrolabe

Selected object

The experiment deliberately uses fewer details, stronger silhouettes, line-led construction and restrained shading to avoid the generic rendered-icon feel of B7p2.

Each drawing is an original symbolic illustration. The aim is not photorealism but constructional clarity. If this language works, it can be expanded to the rest of the parcel and instrument family before QML implementation.
