## S9 model and candidate interactions

A synthetic 840 by 480 rectangular Shelf envelope holds twelve modules, stable module identifiers, kind, x position, z height above the floor, width, height and explicit support identity. No file identity, directory mapping or native persistence is derived from these fields. Geometry is floor-relative; resizing the outer envelope does not reposition existing furniture. Additive outer ornament and backing engravings are not collision surfaces. All ten original representation assets are unchanged. The mounted art starts ten units to the right of its earlier position to avoid overlapping the conservative owl bounds.

Floor contact is z=0. Wall-mounted board and artwork have explicit wall support. Cubby, rack and board tops can support other modules whose full bounding width fits. Objects cannot rest on sculptures, trays or holder edges. Wall-mounted board height includes fixed thickness and bracket clearance. Rectangular bounds are conservative and must not overlap, leave the envelope, violate support contact or form support cycles. This is not a load-bearing engineering simulation. Moving a support translates all transitive dependents. Height edits raise/lower dependents by the top-surface delta; shrink that would strand an object fails. No proportional scaling, hidden reflow or deletion. Actual scroll motion is unchanged and static in this study.

Browse and Arrange remain mutually exclusive; Browse still cycles synthetic cubby previews rather than navigating real directories. Arrange selection does not activate files or enter cubbies. Pointer dragging shows a provisional outline (invalid in a muted warning color); releasing a valid candidate changes only the draft. S9 originally used a 30-unit vertical capture tolerance; owner feedback identified insufficient one-cell fidelity. S9r1 supersedes absolute-coordinate rounding and that tolerance with relative displacement increments and a bounded, separate support-capture tolerance (see the study record). Keyboard selection/nudge and explicit numeric inspector are available. Snap and grid visibility are independent and share the floor-relative origin and selected interval. Exact support height overrides the snap grid; unchanged dimensions remain unchanged. Changing interval does not move furniture.

Separate arrangement and envelope transactions are mutually exclusive; Apply, Cancel and Undo use in-memory snapshots. Invalid envelope shrink disables Apply. Undo is revalidated against current envelope bounds. Returning to Browse with pending layout changes is blocked until explicit resolution. Appearance controls remain study scaffolding, not finalized contextual customization. No native implementation, state schema, directory movement, file operation, scroll dynamics, door swing, fixture creation/removal, checkpoint serialization, support solver for irregular geometry, automated envelope expansion or cross-container navigation is implemented.
