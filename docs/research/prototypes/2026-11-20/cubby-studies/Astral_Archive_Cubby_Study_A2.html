Cubby · Study A2

One empty enclosure. Furniture is added only when you ask for it. Hex rack, shelf, and cubby modules are separate, freely placeable boxes.

Insert a module

Or right-click empty interior to add a module exactly where you want it. No preset is loaded by default.

Outer cubby

Right-click the frame for expansion options. Shrinking never clips an existing module.

Selected module

Select a module to edit its position, size, color, and rack cell size.

Arrangement

Drag a module to move it; drag the small corner square to resize. Modules cannot intersect, but their edges may touch to tile together.

Optional examples

Examples are ordinary arrangements built using exactly the same empty cubby and modules.
