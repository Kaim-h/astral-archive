# Astral Archive — Cubby Study B6r12b: Session 2 review candidate

**Status:** browser-only research on a dedicated review branch; not a B7 acceptance or native QML port. Derived from B6r12a on `c53be325`; B6r12a and previous studies remain unchanged.

## Implementation and interaction

- The main rack now displays a single provisional transaction draft during movement. Its scroll records carry positions; temporary velocity/contact records reference those records. The committed rack and case remain unchanged until a bounded, valid settle succeeds. A 120 Hz fixed step, spring-damped drag, mass-weighted collision correction, friction, low bounce, polygon projection and quiet/support checks are adapted from P2R and the previous seed solver. Only affected cells wake; sleeping cells no longer request frames. Escape, an invalid drop and lifting then returning to the origin discard the complete draft.
- Within a cell, a scroll follows a spring tether and pushes its neighbors; lifting across the wall removes it from the provisional source, which settles. The carried glyph still uses the high-z layer. A destination begins settling on release; the case uses the same provisional inventory. No permanent change of scroll radius is permitted. Failure is a bounded-search refusal, not proof of impossibility.
- Select a Scroll Case record, use **Prepare insertion**, choose a cell and hover/click a connected void to lock it; Shift-click attempts a crowded point. **Insert at void** starts the live transaction, and **Drop from top** searches only a clear upper entry. The original P2R clearance-field regions and smoothed contours are adapted to the clipped rack polygon and masked by actual scrolls. Ctrl+V and Return to origin remain convenient explicit alternatives. The case remains proximity based and the original cradle/register artwork is retained.
- Rack adjustment uses the same visible module renderer (one rack, with a provisional outline). The worker plans without mutating records or the ID allocator. An unchanged radius/size is an exact no-op. Preserve the original lattice key, stable ID and paint first; a center shift alone does not demand relocation review. The planner does not use global assignment. Unresolved cells are marked; choose specific scroll IDs and destinations via selectors or Pick on rack. Multiple destinations and the Scroll Case are supported; only empty unpainted destinations are available, so existing populated groups and independent painted identities cannot be stolen. If an original address disappears, the selected successor can inherit the original identity. New split successors receive new IDs and ancestry. Empty paint that disappears requires explicit resolution. Apply routes through the same atomic ownership transaction; Cancel is non-mutating. A new dimension revision clears choices.
- One Undo history for direct rack motion, case transfers, resize and cell paint; cross-cubby navigation no longer clears it. Newer non-transactional furniture edits block stale Undo rather than overwriting a newer layout. The local B6r12b checkpoint is separate from B6r12a/B6r11. No real files or OS clipboard are manipulated.
- Rack-focused editor and iframe remain inaccessible through ordinary rack interaction, and the full-rack ghost route is replaced. Historical dormant code is retained until replacement regression tests and owner review warrant safe deletion; non-rack fixture inspection remains intact. This deliberately avoids pretending that removing old functions by name proves behavioral equivalence.
